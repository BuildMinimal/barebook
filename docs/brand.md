# Brand

## Name: Barebook

- **"Bare books"** is the real stationery term for blank ledger books - what
  bookkeepers literally bought before software existed. You fill the bare book
  with your business.
- **"Bare"** is the design promise: bare-necessities software. No features you'll
  never use, no SaaS subscription, no lock-in - one container, one file.

## Tagline

> **The bare-necessities freelancer CRM. Clients, work, and money in one book.**

## Design principles

1. **Bare by default.** Every screen earns its place. If a feature doesn't serve
   the track → bill → get paid → nudge loop, it doesn't ship.
2. **One book.** Clients, hours, invoices, payments live in one SQLite file -
   backup is a file copy.
3. **Yours, entirely yours.** Self-hosted, MIT, your SMTP, your Stripe key.
   No telemetry by default.
4. **Non-developer deployable.** Setup wizard on first run; the terminal is
   optional, never required.
